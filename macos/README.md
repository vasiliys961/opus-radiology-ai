# Звонок после завершения этапа Opus Radiology AI (macOS)

## Когда звучит звонок

Наблюдатель работает на MacBook, а не внутри ChatGPT.

- Не звонит после каждого коммита, push, успешного теста или открытия PR.
- Звонит один раз после объединения (merge) PR в main, когда в описании PR разработчик указал точный служебный маркер завершения этапа: OPUS_STAGE_COMPLETE, окружённый обычными знаками HTML-комментария.
- Проверяет публичный GitHub примерно раз в 3 минуты.
- Использует macOS /usr/bin/afplay и стандартный системный звук; также пробует показать уведомление.
- Mac должен быть включён, с активной пользовательской сессией, звуком и интернетом. При сне Mac звонок может прозвучать после пробуждения.
- Не требует GitHub token, разрешения на микрофон, AI-ключей или медицинских файлов.
- Первая проверка записывает прошлые завершённые этапы без звука; установщик сам проигрывает тестовый звонок сразу.

## Установка (после объединения PR с установщиком)

Если репозиторий уже находится на рабочем столе, открой Terminal и введи:

    cd ~/Desktop/opus-radiology-ai-github
    git pull --ff-only
    bash macos/install-stage-chime.sh

Если путь другой, открой Terminal в корне клонированного репозитория:

    git pull --ff-only
    bash macos/install-stage-chime.sh

Установщик добавляет LaunchAgent только в твою пользовательскую сессию.
После установки должен прозвучать тестовый звонок. Если звука нет, проверь
Системные настройки → Звук → Выход и громкость.

## Управление

Проверить звук повторно:

    python3 "$HOME/Library/Application Support/OpusRadiologyAI/stage_chime.py" --test

Посмотреть уже записанные этапы:

    python3 "$HOME/Library/Application Support/OpusRadiologyAI/stage_chime.py" --status

Посмотреть журнал:

    tail -n 30 "$HOME/Library/Logs/OpusRadiologyAI-stage-chime.log"

Удалить установку:

    bash macos/install-stage-chime.sh --uninstall

Старые номера PR не удаляются, чтобы после переустановки не прозвучали
повторные сигналы. Файл истории:
~/Library/Application Support/OpusRadiologyAI/stage-chime-state.json

## Протокол завершения этапа (для разработчика)

1. Реализовать законченный этап на отдельной ветке.
2. Открыть PR, убедиться в успешных unit-тестах, сборке и нужных браузерных проверках.
3. Явно отметить завершение этапа в описании PR строкой:

    <!-- OPUS_STAGE_COMPLETE -->

4. Объединить PR с main.

**Именно это событие запускает звук**, а не каждый успешный GitHub Actions.
Один объединённый завершённый PR → один короткий звонок.

Звуковой сигнал не означает, что медицинское приложение получило клиническую
валидацию — он только указывает на завершение этапа программной разработки.

## Безопасность и ограничения

Перед установкой можно просмотреть код. Скрипт копирует Python-наблюдатель
в ~/Library/Application Support/OpusRadiologyAI, создаёт пользовательский
LaunchAgent и проверяет только публичные сведения о PR нашего репозитория.
Для звука использует /usr/bin/afplay. Не читает DICOM и не отправляет
какие-либо данные пациентов.
