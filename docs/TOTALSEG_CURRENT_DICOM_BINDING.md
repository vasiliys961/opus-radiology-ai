# Audit Astra P0 — TotalSegmentator mask ↔ current DICOM binding

Status: proposed in PR #80; check **live main and CI** before claiming implemented.

The old \`opus-totalseg-native-mpr-slab/v1\` and
\`opus-totalseg-abdomen-native-mpr-slab/v1\` passports bound a label-mask
SHA to a *declared* source CT NIfTI SHA. The browser compared the slab
geometry with the currently open DICOM MPR but **did not check that those
current DICOM pixels were the original input**. Two different studies
can have identical grid positions.

The new optional field generated by the opt-in public LCTSC workflow:

\`\`\`json
{
  "sourceDicomSelectedFrameSha256": [
    "<lowercase SHA-256 for raw DICOM selected slice 0>",
    "<lowercase SHA-256 for raw DICOM selected slice 1>"
  ]
}
\`\`\`

Entries must be in the exact original *sorted selected file order* and
cover the whole selected native mask slab. For native 32-slice research
range 35..66, the source reference has all 103 per-frame DICOM SHA-256
digests and the extraction script emits the exact 32 at indices 35..66.
This value is an optional producer feature, but **mandatory for
browser DICOM source-verified research import**.

The browser performs bounded **streaming SHA-256** directly on each
currently loaded original DICOM \`File\` (never on a JPEG/screenshot,
voxel samples, or an arbitrary identity asserted by the user).
It requires matching count, exact original zero-based slab start/end,
source frame count, original series geometry, consistent study/series/
frame-of-reference UIDs, and exact per-file hashes in sorted order.
Mismatched pixels with identical grid/UIDs fail closed.
Only after that verification does the research label-mask overlay load;
runtime also performs the existing LPS affine/shape check.

**Intentional compatibility boundary:** previously saved TotalSegmentator
passports without \`sourceDicomSelectedFrameSha256\` can no longer be
imported *as verified TotalSegmentator research masks in DICOM MPR*.
Reproduce the passport with the independently pinned source DICOM files.
The existing ordinary \`.nii\` mask import is still available with its
explicit unverified-source warning. Independent R231 packaged-result SHA
and local/full-CT inference proofs, native NIfTI CT+mask matched-source
viewer, 2D DICOM, MPR/3D and the lung/abdomen model tasks are unchanged.
No inference is automatically triggered or repeated.

An exact hash proves data equality against **the uploaded manifest**,
not trusted clinical origin, identity, model quality, signed attestation,
anatomical completeness, or consent. Do not put real DICOM/digests/PHI in
GitHub. The normal CI tests use synthetic nonpatient bytes only; the
manual public TCIA full model workflow produces private ephemeral proofs
and deletes the files on completion. Mac M1/Safari RAM/swap acceptance
is separate.
