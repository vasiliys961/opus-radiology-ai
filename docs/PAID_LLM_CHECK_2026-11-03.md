# Реальная платная проверка Gemini/Opus — 03.11.2026

Выполнены шесть настоящих модельных вызовов через существующее локальное
подключение: для каждого из двух изображений — Gemini, независимое визуальное
чтение Opus и финальное текстовое согласование Opus. Все четыре HTTP-запроса
приложения завершились 200; оба визуальных чтения — `completed`. Подмен нет.
Настроенные идентификаторы: `google/gemini-3.8-flash`,
`anthropic/claude-opus-5.5`; версия фактического backend независимо не проверялась.

## Данные и метод

LongCIU: [публикация авторов](https://www.nature.com/articles/s41597-025-04709-2),
[данные DOI](https://doi.org/10.25820/data.007301),
[авторский код](https://github.com/MICLab-Unicamp/LongCIU).
README набора явно разрешает использование по ODC-By и описывает согласие на
распространение обезличенных изображений. Carmo et al., Long COVID Iowa-UNICAMP
(2024), University of Iowa. Зеркало MedOtter/LongCIU закреплено ревизией
`c4b975090c16fabe59079a528dd920d956e16c66`.

До просмотра масок выбраны индексы 0 и 40 из авторского test split. Это **два
независимых исходных 2D-среза**, не соседние срезы одной серии и не два полностью
проверенных исследования. Каждый 512×512 HU-срез показан в двух окнах одного
уровня: LUNG −600/1500 и SOFT 40/350, рядом, без изменения разрешения.
Точные PNG просмотрены, локальный OCR проверен; его 8/12 областей оказались
ложными срабатываниями на изображении без текста. Маски, название набора,
диагноз и исходные индексы провайдерам не передавались. Маски открыты только
после сохранения обоих полных ответов. Первый Opus не видел ответ Gemini.

## Сопоставление с экспертным STAPLE

| Срез набора | Экспертные пиксели: матовое стекло / консолидация | Gemini | Итог Gemini → Opus |
| --- | --- | --- | --- |
| 0 | 5998 / 885 | Оба признака названы | Оба признака названы |
| 40 | 21535 / 2262 | Матовое стекло названо; консолидация отдельно не выделена | Оба признака названы; консолидация добавлена независимым визуальным Opus |

Это ручное семантическое сопоставление помощником, **не экспертная adjudication**,
не проверка локализации каждого очага и не Dice. Отсутствие упоминания
консолидации у Gemini не равно явному отрицательному заключению.
Чувствительность/специфичность по этим данным не заявляются: два положительных
среза, отрицательных полных исследований нет, пересечение с обучением LLM неизвестно.

## Что проверка выявила помимо совпадения

- Модели предполагали сторону по конвенции отображения при неизвестной ориентации.
- На срезе 40 визуальный Opus предположил контрастирование; набор описывает
  бесконтрастную КТ. Финал сохранил оговорку, но не убрал предположение полностью.
- На срезе 0 Opus добавил подозрение на образование корня; на срезе 40 появились
  противоречивые оценки сердца. Эти находки не размечены данным набором:
  объявлять их истинными или ложными по двум классам STAPLE нельзя.
- Итоговые дифференциальные ряды многословны. Следующая практическая доработка —
  запрет выводить сторону/контраст из догадки и отделение слабых дополнительных
  гипотез от основного заключения с проверкой врачом.

Результат поддерживает полезность независимого визуального чтения, но не
доказывает превосходство над материнским приложением или клиническую готовность.
МРТ и полные исследования в этой проверке не оценивались.

После этого запуска инструкции всех трёх стадий ужесточены: исключена догадка
о стороне/контрастировании, слабые гипотезы вынесены в описание для проверки
врачом, дифференциальный ряд ограничен тремя обоснованными вариантами. Старое
разрешение стороны «предположительно» удалено из общего промпта. 684 локальных
теста и TypeScript проходят; они проверяют проводку инструкций, а не качество
нового ответа LLM. Повторных платных вызовов после этой доработки пока нет.

## Расходы и воспроизведение

Ответы заняли примерно 60 и 53 секунды на пример. Суммарные provider receipts:
15 384 входных и 8 076 выходных токенов. API приложения не возвращает фактическую
списанную сумму; точная стоимость здесь не заявляется, её нужно смотреть в
биллинге подключённого провайдера. Автоматических повторов оплаченных вызовов нет.

Технические результаты, хеши и квитанции:
[verification/longciu-paid-gemini-opus-20261103.json](verification/longciu-paid-gemini-opus-20261103.json).

`/tmp/opus-longciu-paid-20261103/run-001`; каталог временный.

Подготовка закреплённых открытых файлов, уже полученных по указанной ревизии:

`node --experimental-strip-types scripts/check-paid-longciu-llm.mjs --prepare-pngs /tmp/opus-longciu-paid-20261103`.
Проверка точных PNG человеком и `reviewed-pngs.json` обязательны.
Платный запуск — только явным `--execute-paid-reviewed-case-pngs <source> <new-output>`;
существующий output запрещает случайную повторную оплату. Он не подключён к CI.
Ключи скрипт не читает: используется одобренный signed-session маршрут localhost.
