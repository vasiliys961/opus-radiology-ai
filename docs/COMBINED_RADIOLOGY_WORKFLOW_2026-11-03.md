# Объединённый локальный поток Gemini / Opus — 03.11.2026

После выбора врачом кадров Gemini теперь составляет не только список подозрений,
но и структурированное наблюдательное описание видимых органов. Передаются
морфология, локализация, важные отрицательные признаки, ограничения видимости
и качество каждого изображения. Все описания привязаны к исходным номерам.
Неоценённые структуры и недиагностические изображения не могут давать
структурированные отрицательные признаки. Отбор для перепроверки — отдельный
канал; он не фильтрует подробные наблюдения, передаваемые в заключение.

Независимый визуальный Opus не видит описания Gemini заранее. Для небольшого
выбора до 16 кадров он получает весь обработанный набор, даже без отмеченных
изменений, насколько позволяют прежние лимиты размера и четырёх пакетов.
Если кадры не поместились, их исходные номера перечисляются как непросмотренные.
Для длинной серии сохранён целевой отбор: очаговые/неясные срезы и привязанные
детекторные находки, до 16; без таких оснований отдельного визуального вызова нет.
Дополнительное окно КТ остаётся видом того же исходного среза.

Финальный Opus согласует ВСЕ принятые наблюдения и органные описания Gemini,
независимое чтение, клинический контекст и доступные реальные детекторные факты.
Ему явно запрещено распространять отрицательные признаки за пределы выборки,
скрывать расхождения, считать отсутствие детектора нормой или выдумывать
измерения/последовательности/контрастные фазы. Финальный синтез текстовый;
визуальное чтение выполняется отдельным предыдущим запросом.

Новый JSON провайдера строго проверяется. Старые локальные квитанции без
органного описания сохраняют совместимость. Gemini имеет потолок 3500 выходных
токенов на группу, отражённый в резерве и предварительной стоимости. Контекст
финального Opus по-прежнему ограничен 110000 символами и 180 наблюдениями:
переполнение вызывает явную ошибку, данные не обрезаются молча. Крупные серии
с насыщенными описаниями могут достигать этого ограничения; автоматическое
иерархическое объединение описаний пока не реализовано.

## Реальная проверка

Из локальной пользовательской папки NLST загружены 150 исходных DICOM;
врачебный выбор 60–69, лёгочное и мягкотканное окна. Передавались только ранее
проверенные копии PNG: совпали все десять SHA с просмотренными ранее копиями.
Исходные DICOM и идентификаторы в облако не передавались.

- Пять настоящих Gemini HTTP 200, группы 3+1+3+1+2; оценены 10 кадров.
- Богатый JSON: 4/3/4/4/4 описаний структур, качество для каждого из 10 кадров.
- Независимый визуальный Opus успешно просмотрел все срезы 60–69.
- Финальный Opus HTTP 200, русский протокол 5345 символов, точный охват 10/150.
- В протоколе сохранено расхождение двух прочтений и невозможность измерений.
- 150.433 секунды после отправки; 7 настоящих вызовов моделей, без моков.
- Gemini: 16050 входных / 6739 выходных токенов; Opus вместе со слепым
  просмотром: 19511 / 3785. Расчёт по ранее проверенным тарифам — $0.191053,
  не подтверждённый провайдером биллинг.

696 unit-тестов, TypeScript и отдельный браузерный сценарий без подозрительных
кадров прошли. В последнем проверен независимый просмотр всех 9 выбранных
кадров при пустом triage; ответы провайдера там синтетические. Это отдельно
от настоящего платного NLST-прогона, где ответы не подменялись.

Агрегаты: `verification/combined-nlst-ten-real-browser-20261103.json`.
Сырые ответы, точные копии и отчёт остаются только в
`/tmp/opus-combined-nlst-ten-20261103-01`, не в git.

Это проверка работающего пользовательского пути, не клиническая валидация:
экспертной разметки этого случая нет, детекторы в прогоне не выполнялись.
Превосходство над материнским приложением не установлено; требуется сравнение
на одинаковых размеченных исследованиях. Новых моделей, сервера и деплоя нет.
