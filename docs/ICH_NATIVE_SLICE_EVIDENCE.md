# PATH-ICH-02 — проверка локализации пропусков SAMIHS по срезам

**Статус: реализован исследовательский расчёт; реально выполненный запуск SAMIHS на открытой КТ и Dice на реальном случае пока не подтверждены.**

После получения **настоящей** предсказанной маски SAMIHS и законно используемой экспертной 3D-маски достаточно одного вызова `scripts/ich-native-slice-evidence.py`. Он сначала запускает действующий `evaluate-ich-public-mask.py`: проверяет SHA-256 исходной КТ, предсказания и эталона, форму, affine, миллиметры и бинарные метки; затем считает совпадения **на каждом исходном воксельном срезе**, без искусственных срезов, перенормировки или догадки о диагностике.

```bash
python scripts/ich-native-slice-evidence.py \
  --source /research/authorized-ct.nii.gz \
  --prediction /research/samihs-public-ich-mask.nii.gz \
  --reference /research/expert-ich.nii.gz \
  --report /research/opus-ich-samihs-public-report.json \
  --reference-sha256 <REAL_EXPERT_MASK_SHA256> \
  --output /research/ich-3d-comparison.json \
  --slice-output /research/ich-source-slices.json \
  --reference-label 1 \
  --rights-attested \
  --public-research-authorization PUBLIC-ICH-REFERENCE-REVIEW
```

В интерфейсе: **SAMIHS → подтвердить SHA исходной КТ и маски → экспертное сравнение → подтвердить SHA экспертной маски → загрузить отчёт распределения по срезам**. Новый блок показывает экспертно положительные срезы без перекрытия и уровни с наибольшими FN/FP. Браузер перепроверяет суммы TP/FP/FN всех срезов против прежних 3D-метрик, SHA всех трёх файлов, число и ось исходных срезов. Это целевая навигация для врачебного анализа ошибок, **а не** полнота диагностики, истинные номера исходных DICOM SOP или независимая клиническая валидация.

## Первое выполнение реального инференса всё ещё необходимо

1. Установить официальные SAMIHS wrapper/checkpoint из [публичного репозитория модели](https://huggingface.co/MooreMuaMu/samihs-ich-segmentation) на уполномоченной внешней CUDA-машине; фиксировать ревизии и SHA, изолировать запуск. Hugging Face Inference Provider для модели на момент проверки не предлагает готовый endpoint.
2. Выбрать только источник, для которого подтверждены условия использования **именно этой версии** и право загрузки в выбранную вычислительную среду, проверить нативную сетку и ось. Не загружать данные пациента на GitHub.
3. Запустить `scripts/run-samihs-ich-public.py` с проверенными аргументами SHA. Выходы: настоящая маска и отчёт с временем выполнения.
4. Запустить приведённую выше команду; получить Dice/HD95, ошибки в мл и срезы с пропущенной разметкой. Сохранить только безопасные метаданные, не исходные изображения и маски, в репозитории.

**Ограничения источников:** [INSTANCE2022](https://instance.grand-challenge.org/) объявил публичную доступность в сентябре 2026, но это не отменяет собственных правил использования и подписанных соглашений. [PhysioNet CT-ICH v1.2.0](https://physionet.org/content/ct-ich/1.2.0/) маркирован как CC BY 4.0, однако файлы этого старого релиза сейчас недоступны; [v1.3.1](https://physionet.org/content/ct-ich/1.3.1/) требует отдельного одобрения и доступа. BHSD — NCND/noncommercial по официальному GitHub. Ни один из этих наборов не выбран по умолчанию и не скачивается приложением без отдельной проверки прав.

## Поддержка нативного типа пикселей публичной КТ

После SHA-проверки источника браузерный NIfTI-k просмотр поддерживает скалярные CT-типы uint8, int8, int16, uint16, int32, uint32, float32, float64 и ограниченные диапазоном безопасного целого int64/uint64. Значения преобразуются только для отображения в Float32 текущего среза: исходный NIfTI и маски остаются неизменными. Отрицательные значения, масштаб NIfTI slope/intercept и физическая сетка сохраняются при чтении. Память ограничена одним срезом; маска модели по-прежнему обязана быть бинарной uint8. Целые выше безопасной точности JS отвергаются, а слишком большой распакованный объём блокируется. Чтение отображения не заменяет верификацию оригинального DICOM/HU.
