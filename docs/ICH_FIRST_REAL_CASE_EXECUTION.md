# PATH-ICH-04 — один подлинный случай SAMIHS → экспертная маска

**Статус: единый исполнитель реализован. Подтверждённых запусков предобученной SAMIHS по публичному случаю с экспертной маской пока НЕТ.**

Путь `scripts/run-ich-first-real-case.py` сводит четыре уже существующих реальных вычислительных шага в один **без замены** инференса моделированием, повторением срезов или самодельной экспертной разметкой:

1. Сверить SHA-256 настоящей исходной КТ и эталонной маски, наличие аудированной модели, явную исследовательскую правомерность и внешний Linux CUDA.
2. Запустить штатный `scripts/run-samihs-ich-public.py` на **полном исходном 3D NIfTI**, из проверенного предобученного checkpoint и поставляемого с ним `segment_ich.py`. Обязательный guard GPU VRAM >=12GiB и batch <=8 остаётся действующим.
3. `scripts/ich-expert-component-contact.py`: получить независимый Dice, HD95 и совпадения 3D-компонент с настоящей экспертной маской.
4. `scripts/ich-native-slice-evidence.py`: получить покадровое распределение TP/FP/FN и пропущенные экспертные уровни.
5. Сверить модель/вход/маску/эталон по SHA, 3D метрики между двумя независимыми вычислениями и полноту всех JSON. **Только после этого** написать `opus-ich-first-public-case-complete.json`.

```bash
python scripts/run-ich-first-real-case.py \
  --model-dir /research/audited-samihs \
  --input /research/authorized-head-ct.nii.gz \
  --expert-mask /research/authorized-expert-mask.nii.gz \
  --output-dir /research/ich-first-real-results \
  --source-sha256 <REAL_CT_SHA256> \
  --reference-sha256 <REAL_EXPERT_SHA256> \
  --checkpoint-sha256 <REAL_SAMIHS_WEIGHTS_SHA256> \
  --wrapper-sha256 <AUDITED_SEGMENT_ICH_PY_SHA256> \
  --dataset-citation-url https://example.org/original-authorized-dataset \
  --slice-axis 2 --reference-label 1 \
  --batch-size 1 --threshold 0.5 \
  --max-model-seconds 3600 \
  --rights-attested --upstream-model-audited \
  --public-research-authorization PUBLIC-ICH-FULL-CASE
```

Запуск только на авторизованном **внешнем GPU Linux** с локально установленными Torch CUDA, nibabel, numpy, scipy и полными зависимостями SAMIHS. Скрипт не устанавливает пакеты, не скачивает данные/веса, не запускает модель на Mac и не отправляет данные в Hugging Face/API/GitHub. Никаких платных GPU он сам не арендует. При ошибке он оставляет только частичные локальные артефакты **без** `opus-ich-first-public-case-complete.json`.

**Важно:** отметки `--rights-attested` и `--upstream-model-audited` являются утверждениями оператора, не юридической верификацией OpenAI/Opus. Правила INSTANCE2022 по-прежнему ограничивают использование данным соревнованием и требуют подписанного соглашения, даже при открытом скачивании; нельзя выдавать этот набор за автоматически разрешённый. PhysioNet CT-ICH v1.3.1 ограничен соглашением, старый v1.2.0 недоступен для новых скачиваний. Другие наборы (например, Zenodo Seg-CQ500 или SAH) также нуждаются в отдельной проверке условий лицензирования как исходной КТ, так и самой экспертной разметки.

Сохранить на сервере исходную КТ и экспертную маску для врачебной проверки; **не** коммитить ни пиксели, ни маски, ни идентификаторы пациента в репозиторий. Признаки уровня case из полученного JSON не дают клинической чувствительности/специфичности, доказанного held-out качества, идентификации типа кровоизлияния или исходного DICOM SOP.

Финальный `opus-ich-first-public-case-complete.json` является воспроизводимым техническим следом выполненной цепочки, но **не** независимой гарантией аудита авторства публичной разметки, весов модели или корректности диагноза.

## Непрерывная проверка многоклассового эталона (PR #111)

Если экспертные IPH/IVH/SAH/SDH/EDH метки были предварительно объединены
`build-ich-expert-binary-union.py`, единый runner принимает **три дополнительные
опции одновременно**. Если передать только одну или две, старт настоящей
SAMIHS блокируется до выделения CUDA памяти:

```bash
  --expert-mask /research/derived-expert-ich-binary.nii.gz \
  --reference-sha256 <SHA_DERIVED_BINARY_EXPERT_MASK> \
  --derived-expert-manifest /research/derived-expert-ich-binary-manifest.json \
  --original-expert-mask /research/original-multiclass-expert.nii.gz \
  --label-ontology-json /research/dataset-authoritative-labels.json
```

Перед инференсом сверяются SHA исходной КТ, полученного бинарного эталона,
оригинальной неизменённой экспертной маски и оригинального словаря классов.
Отдельно проверяются происхождение, точное соответствие словаря и количеств
вокселей каждого геморрагического класса. В успешный итоговый паспорт попадут
хеши оригинальной разметки, онтологии и её публичная ссылка, но **не пиксели**.
Отсутствие доказанной независимости врачебной разметки и прав на использование
сохраняется даже после совпадения SHA-256.

Обычный одно-классовый эталон по-прежнему принимается без трёх добавленных
опций и явно обозначается как не произведённый из многоклассового.

## Совместимость полной КТ (PATH-ICH-05)

Модуль 3D-контактов теперь принимает тот же предельный объём (512×512×400),
что и исполнитель SAMIHS и независимый оценщик. Ранее типичная
КТ 512×512×130 отклонялась только из-за ограничения 30 млн вокселей
после уже проведённого GPU-инференса. Модуль остаётся offline и требует
достаточной оперативной памяти внешнего исследовательского сервера.

Для HD95 доступен второй точный, несэмплированный алгоритм
по ближайшим точкам поверхностей (scipy.spatial.cKDTree) на ортогональной
исходной сетке. Он применяется, когда ошибочные кандидаты разнесены по КТ,
а прямое 3D EDT всего bounding box потребовало бы слишком много RAM.
Ограничение 250000 точек каждой поверхности и 3 млн положительных вокселей
сохраняется; при превышении возвращаются hd95Mm=null и
hd95UnavailableReason вместо выдуманного числа.
Никаких новых диагнозов или подтверждённого SAMIHS-инференса эта правка не создаёт.

## Аутентичность официальных весов SAMIHS (PATH-ICH-09)

Для первого настоящего случая зафиксирована официальная ревизия репозитория
`MooreMuaMu/samihs-ich-segmentation` на Hugging Face:
`29aaa1287ca35b19e40495bd4966fa2923871cb9`.

Опубликованный на Hugging Face Xet pointer SHA-256 checkpoint
`weights/SAMIHS_09170527_2_0.483.pth`:

`b4c5ff729b906605555f83359120341a72035d1b6a784a9fef7dd61ee09a639e`

Источник: https://huggingface.co/MooreMuaMu/samihs-ich-segmentation/blob/main/weights/SAMIHS_09170527_2_0.483.pth

И единый исполнитель, и непосредственный GPU-адаптер теперь отвергают
любой другой checkpoint SHA-256 **до инференса**. Фактический checkpoint
проверяется по байтам на исследовательском Linux GPU-хосте. Завершённый
паспорт указывает официальную ревизию. Это исключает ошибочное указание
произвольных весов как исходной SAMIHS, но **не удостоверяет** безопасность
PyTorch pickle, исходного Python wrapper или зависимостей и не подтверждает
право на использование КТ. Хеш wrapper по-прежнему должен быть независимо
получен и проверен оператором; опубликованный Git blob SHA-1 не следует
выдавать за SHA-256 файла. Все файлы загружаются вручную в изолированную
исследовательскую среду. Ни GH Actions, ни MacBook Air не проводят реального
GPU SAMIHS-инференса.
