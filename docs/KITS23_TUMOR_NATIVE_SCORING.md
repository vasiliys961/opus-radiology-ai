# KiTS23 original renal cancer model — source-native scoring gate

Run the real original `KS987/PanCancerSeg-Specialized-weights` trained
`Dataset102_Kidney` nnU-Net model **separately** on the admitted original
KiTS23 `case_00021`. The only accepted reference is original source
SHA256 `c8fc76065ce316d6935c3dc87490606381d19fbff1bdd43616814e0cde0c0637`
and expert mask SHA256
`0292f2683b376043f478788624a8fdd924ce736c98626378fb897d4723991b50`.
Verified original checkpoint SHA256:
`5a1c9e2894160d50dfa0f8c0ac0a88198897973f642c0cbeb33e935457fd9d8c`.

After a **real, completed** original publisher inference, with the output
mask resampled back to original source grid using verified transform if needed,
score it with:

```bash
python scripts/score-kits23-original-renal-tumor.py \
 --source /private/kits23/original-imaging.nii.gz \
 --expert /private/kits23/original-segmentation.nii.gz \
 --prediction /private/kits23/original-prediction-native.nii.gz \
 --checkpoint /private/KS987/checkpoint_best.pth \
 --output /private/kits23/renal-tumor-numeric.json
```

**Safety:** the scorer checks original CT and expert bytes, full original
trained checkpoint hash, native physical grid and integer mask class2
(renal tumor, **not** kidney class1 or cyst class3). It streams individual
2D slices for bounded memory, computes TP/FP/FN, Dice, voxel recall, 
original source coordinate bounds and conditional mm-based mL.
An unregistered or probability-only prediction is refused.
The expert mask is never passed to the model by this scoring tool.

This tool does NOT execute pretrained inference and cannot prove that its
input mask was generated by that model: the genuine original nnU-Net
workflow must separately attest forward logs, model/config and output.
A single source may overlap KS987 training, so independent clinical accuracy
is unknown; no patient-use permission. Never publish CT, reference, prediction,
patient metadata or checkpoint to GitHub artifacts.
