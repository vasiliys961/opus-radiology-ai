# PATH-ICH-05 · многоклассовая экспертная разметка → бинарный эталон кровоизлияния

Для SAMIHS бинарная маска объединяет внутричерепные кровоизлияния независимо от локализации и подтипа. Многие исследовательские датасеты размечают IPH, IVH, SAH, SDH и EDH **разными числовыми ID**. Сравнение маски SAMIHS только с `--reference-label 1` тогда систематически игнорировало бы часть геморрагических вокселей.

Новый `scripts/build-ich-expert-binary-union.py` выполняет только оператором документированное объединение всех указанных геморрагических ID в **новую** бинарную NIfTI маску со строго прежней геометрией. Исходный экспертный файл не меняется. Ни одна неизвестная ненулевая метка не интерпретируется по догадке: программа отказывает. Она сохраняет SHA исходной КТ, исходной многоклассовой разметки, проверенного описания классов и вычисленной бинарной маски, плюс числа вокселей каждого класса. Без ресемплинга или классификации нейросетью.

### Явный документ источника (пример структуры, НЕ универсальный словарь меток)

```json
{
  "sourceUrl": "https://example.org/exact-dataset-label-ontology",
  "labelMeaning": {
    "1": "IPH",
    "2": "IVH",
    "3": "SAH",
    "4": "SDH",
    "5": "EDH"
  }
}
```

**Цифры выше только иллюстрация формата.** Не применять их к реальному датасету до проверки оригинального словаря классов и прав доступа. Если типы и их числовые ID неизвестны, **отказаться**, а не угадывать.

```bash
python scripts/build-ich-expert-binary-union.py \
  --source-ct /research/authorized-head-ct.nii.gz \
  --expert-labelmap /research/original-multiclass-expert.nii.gz \
  --label-ontology-json /research/dataset-authoritative-labels.json \
  --output-mask /research/derived-expert-ich-binary.nii.gz \
  --manifest /research/derived-expert-ich-binary-manifest.json \
  --source-sha256 <CT_SHA256> \
  --expert-sha256 <ORIGINAL_LABELMAP_SHA256> \
  --ontology-reviewed --rights-attested \
  --public-research-authorization PUBLIC-ICH-LABEL-UNION
```

После вывода бинарной маски подать её в `scripts/run-ich-first-real-case.py` как `--expert-mask`, используя именно её SHA-256 (из нового манифеста). Сохранить оригинальный экспертный файл и манифест преобразования: они нужны для независимого аудита. Текущий объединённый отчёт SAMIHS **не устанавливает тип** кровоизлияния, не является новым экспертным заключением и не доказал клинической точности. Все действия — только на разрешённых исследовательских данных и внешнем Linux CPU/GPU.

**Текущий фактический статус:** программная обработка подготовлена. Конкретные разрешённые исходные КТ/веса SAMIHS/проверенный экспертный mask и метрики реального выполнения до сих пор отсутствуют.
