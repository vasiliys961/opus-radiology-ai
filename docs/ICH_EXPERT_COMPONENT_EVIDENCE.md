# PATH-ICH-03 · сравнение 3D-фрагментов кровоизлияния с экспертной разметкой

**Исследовательский код реализован, подтверждённого на публичной КТ инференса SAMIHS пока НЕТ.**

Новая программа `scripts/ich-expert-component-contact.py` вычисляет контакт между всеми **6-связными компонентами** бинарной SAMIHS маски и компонетами независимо размеченной экспертной маски. Результаты содержат границы каждой крупной компоненты в нативных индексах NIfTI, объём (мл), долю пересечения, компоненты без пересечений, связи одна-ко-многим (предупреждение о слиянии/дроблении маски), без подмены на клиническую чувствительность или диагноз. Исходный `evaluate-ich-public-mask.py` сначала удостоверяет SHA-256 исходной КТ, обеих масок, физическую геометрию и 3D Dice/IoU/HD95. Суммы компонет должны точно совпадать с уже проверенными TP/FP/FN.

```bash
python scripts/ich-expert-component-contact.py \
 --source /research/authorized-head-ct.nii.gz \
 --prediction /research/samihs-public-ich-mask.nii.gz \
 --reference /research/authorized-expert-mask.nii.gz \
 --report /research/opus-ich-samihs-public-report.json \
 --reference-sha256 <EXPERT_MASK_SHA256> \
 --output /research/ich-3d-comparison.json \
 --component-output /research/ich-component-contact.json \
 --reference-label 1 --rights-attested \
 --public-research-authorization PUBLIC-ICH-REFERENCE-REVIEW
```

Предохранители для исследовательской RAM: максимум 30 млн вокселей, 4096 компонент на маску и 1 млн перекрывающихся вокселей при построении sparse pair map. При превышении задача останавливается без выдуманных результатов. Код предназначен для внешнего исследовательского CPU/GPU-сервера, **не** для Mac M1 8 ГБ.

Нельзя автоматически объявлять 6-связный фрагмент отдельной гематомой: анизотропия и большой шаг между КТ-срезами могут разбить одно кровоизлияние на несколько компонент. Любое пересечение, даже один воксель, не является доказательством корректной детекции очага. Из модели не выводится подтип (SAH/SDH/EDH/IVH/IPH), нет исходного DICOM SOP сопоставления и не доказана независимость от обучающих исследований.

## Незаполненные фактические результаты
- Веса SAMIHS установлены на разрешённом CUDA-исполнителе: **не подтверждено**.
- Законно используемая пара исходная КТ + экспертная маска размещена на исполнителе: **не подтверждено**.
- Подлинный mask/report SAMIHS и component-contact JSON с реальными числами: **отсутствуют**.

Для первого реального опыта допускаются лишь наборы с индивидуально проверенными правами и условиями работы на выбранном сервере; общий статус «публичный» сам по себе не разрешает копирование. Правила INSTANCE2022 по-прежнему требуют соглашения и указывают challenge-only использование. Исследовательский компонент не подключает облако пациента и не использует платные API.
