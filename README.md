# Opus Radiology AI

Браузерная станция для просмотра DICOM и чернового разбора КТ и МРТ.
Состояние на 4 ноября 2026, ветка `main`, коммит `dca3def`.

Паспорт цели: [docs/OPUS_RADIOLOGY_MASTER_SPEC.md](docs/OPUS_RADIOLOGY_MASTER_SPEC.md).
Требования: [REQUIREMENTS.md](REQUIREMENTS.md).
Правила разработки: [AGENTS.md](AGENTS.md).

Исследовательский прототип. Клинической и регуляторной валидации нет.
Черновик заключения не подписан и не заменяет решение врача.

## Что делает врач

```bash
cd web
npm install
npm run dev
```

Нужен Node.js 22+. В `web/package.json` стоит Next.js 16.4.4.
Откройте адрес из терминала. Корень `/` сразу открывает `/viewer`.
Старая страница остаётся по адресу `/?research=1`.

1. Загрузить исследование DICOM.
2. Нажать «Анализировать исследование».

Программа на этом компьютере готовит обезличенные копии выбранных кадров.
Затем Gemini смотрит эти кадры, а Opus пишет черновик по тому, что реально ушло в запрос.
Оба вызова идут к внешним моделям. На Mac они не считаются локально.
Охват черновика равен переданным кадрам и окнам. Пропущенный орган в тексте — это пропуск описания, а не норма.

Если на этом же компьютере уже отвечает служба с проверенными весами, разбор добавляет её результат.
Молчание службы остаётся состоянием «не оценено».

## Развёртывание весов

Страница `/technical`, блок «Развернуть детекторы».
Скачивание разрешено на Linux с 16 ГБ памяти и 30 ГБ свободного места.
На Mac обе кнопки выключены и в сеть за весами не ходят.

- «Развернуть рентген грудной клетки» — один файл шести признаков, от 10 до 90 МБ. Считается один файл CR или DX.
- «Развернуть все возможные» — тот же рентген, архив лимфоузлов средостения (105 186 900 байт), окраска лёгких Lungmask R231 (не больше 150 МБ) и кровоизлияние для заранее разрешённой публичной КТ головы (161 042 978 байт). Опухоль лёгкого добавляется при 64 ГБ памяти; каждый её файл не больше 400 МБ.

После сверки файла программа ставит закреплённые пакеты Python в отдельное окружение на этом Linux и запускает службы.
Видеокарта для этих весов не требуется.
Служба кровоизлияния считает только заранее разрешённое публичное исследование, уже лежащее на сервере.
ТЭЛА не ставится. Узлы лёгких, выпот, живот, белое вещество, инсульт и глиома этой кнопкой не скачиваются.

Ответившие службы видны кнопке «Анализировать», когда приложение на этом сервере открыто как `http://127.0.0.1:3000`.
