# Opus Radiology AI

Самостоятельный исследовательский прототип браузерной станции КТ/МРТ, использующий идеи и наработки [Doctor Opus](https://github.com/vasiliys961/doctor-opus).

> **Не медицинское изделие. Не предназначено для принятия клинических решений.** Это пилот для работы с синтетическими или корректно обезличенными данными. Точность не валидирована.

## Что действительно работает в v0.1

- Просмотр JPG/PNG/WEBP полностью локально в браузере.
- **Ограниченный предпросмотр DICOM:** один несжатый монохромный кадр (DICOM Part 10, Explicit/Implicit VR Little Endian, 8/16 bit), окно WC/WW, Rescale Slope/Intercept, MONOCHROME1/2. Неподдерживаемые виды изображения отклоняются с сообщением, вместо выдачи ошибочной картинки.
- Добавление нескольких файлов, клинический контекст только в памяти браузера.
- Тесты для DICOM-декодера.

## Что НЕ работает

- JPEG2000/JPEG-LS/RLE DICOM, Enhanced multi-frame, реконструкция полных серий, NIfTI и ZIP (файлы можно добавить в список, но не просмотреть).
- Геометрия DICOM, MPR/3D, численные измерения и сегментация.
- Анализ TotalSegmentator/MONAI/MedSAM, Gemini/Claude/GPT, хранение исследований и отчётов. Эти разделы намеренно обозначены как запланированные.

## Запуск на Mac M1

Нужен Node.js 22+ (проверялось с Node 22, на Mac пользователя установлен Node 24).

```bash
cd web
npm install
npm run dev
```

Открыть `http://localhost:3000`. Для unit-тестов: `npm test`.

### Если на Mac уже запущен старый прототип

Не запускайте `git clone` внутрь существующего `web`, созданного `create-next-app`: там может быть собственный `.git`. Вместо этого сохраните старую папку и клонируйте новую версию **рядом** с ней:

```bash
cd ~/Desktop
# Не удаляет и не изменяет старую папку «Opus Radiology AI»
git clone https://github.com/vasiliys961/opus-radiology-ai.git opus-radiology-ai-github
cd opus-radiology-ai-github/web
npm install
npm run dev
```

Перед вторым `npm run dev` остановите прежний сервер сочетанием `Ctrl+C`, иначе новый процесс может стартовать на порту 3001.

## Архитектурный маршрут

1. На базе существующего Doctor Opus перенести/улучшить DICOM viewing, заменить учебный reader на полноценный Cornerstone3D с поддержкой WADO и DICOM SEG.
2. Выделить Python inference-сервис (FastAPI/MONAI), работающий как отдельный процесс без библиотек PyTorch в Next.js.
3. Добавить маршрутизацию по анатомической области, требованиям моделей и лицензиям; передавать только обоснованные измерения.
4. Независимый анализ изображений → сверка находок → клинический контекст → LLM-синтез через конфигурируемые API.
5. Валидация на независимых тестовых наборах с sensitivity/specificity, FROC, Dice и отдельным врачебным контролем.

**Приватность:** DICOM/PACS исследования и медицинские записи не должны попадать в публичный GitHub. В текущем приложении загрузка остаётся в браузере; внешние вызовы для медицинских данных не выполняются. При подключении LLM API будут отдельные согласия и безопасная деидентификация.

**Лицензии:** структура и прототип созданы независимо. Сторонние модели, веса и части исходников будут добавляться только после проверки условий лицензий. Не копируйте чужие веса в публичный репозиторий.
