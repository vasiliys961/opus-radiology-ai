## Конечный продукт

Единый браузерный DICOM/КТ/МРТ-интерфейс на Next.js и Cornerstone3D. 2D/MPR/3D, полная многосерийная проверка, контроль геометрии и параметров CT/MR, потоковая загрузка больших серий и специализированные AI-модели для большинства локализаций. **Четыре способа вычислений без смены интерфейса:** browser-only лёгкие ONNX модели, локальный Mac/Windows/Linux Python worker с CPU/MPS, частный CPU сервер, частный GPU сервер. **Без обязательной подписки**, при наличии лицензированных открытых весов и локальной вычислительной мощности.

Параллельные медицинские нейросети (Lungmask, TotalSegmentator, MONAI, nnU-Net и другие разрешённые веса) и **опциональные** внешние Gemini/Claude Opus/GPT. Их сообщения не подменяют доказательства: найти серию/срез/ROI, установить координаты и измерения, сохранить неопределённость/несовпадения. Человеческое подтверждение отчёта обязательно. Для реальных пациентов внешняя отправка **заблокирована**, пока фактически не пройдены правовые, технические и клинические проверки приватности; локальная обработка тоже требует соответствующей защиты.

**Mac M1 8 GB:** основной экспериментальный стенд. Не считать его слабым, но не обманываться: текущий NIfTI экспорт ограничен 8 388 608 вокселями, а полноценные исследования могут содержать ~78 млн. Нужны streaming, ROI/tiling, memory preflight, одна модель одновременно, проверка времени/памяти. Сервер должен использовать тот же интерфейс и контракт работы.

## ЧТО УЖЕ ЕСТЬ на 2026-10-11

PR #6–#11 уже в \`main\`: DICOM/2D/MPR/3D; Study Intelligence; экспорт одной совместимой серии в NIfTI и импорт маски с привязкой к источнику; CPU ONNX runner с **только синтетической тестовой моделью**; реальные OpenRouter вызовы только на **искусственных** PNG, без пользовательских DICOM. Нет настоящих медицинских весов, локальной кнопки one-click, приватного GPU worker или клинически проверенного детектора.

## СЛЕДУЮЩАЯ КОНКРЕТНАЯ ЗАДАЧА (R1)

1. Подключить **настоящие веса Lungmask R231** из проверенного источника с лицензией и SHA-256 в отдельном локальном Python-окружении.
2. Создать защищённый локальный AI Worker \`127.0.0.1\` и браузерную кнопку **«Анализировать локально»**, не отправляющую DICOM в интернет.
3. На разрешённой публичной эталонной CT грудной клетки выполнить реальную сегментацию, наложить полученную маску в MPR с проверкой источника/геометрии.
4. Измерить peak RAM и время на Mac M1 8GB, покрыть ошибки/отмену/unsupported, не смешивать с обещанием диагностики заболевания.
5. Затем подключать TotalSegmentator MPS/CPU, большие объёмы потоково, GPU worker, специализированную детекцию патологий, доказательное параллельное объединение с LLM.

**ПРАВИЛА:** не печатать и не менять \`web/.env.local\` с ключом OpenRouter; не использовать устаревший установщик; не выдавать синтетическую сеть за медицинскую; не отправлять снимки пациентов в облако; не пушить прямо в \`main\`, только ветка/PR/CI, merge делает пользователь.
